# Telegram → English translator

Раз в 30 минут GitHub Actions запускает `bot.py`. Бот читает новые посты из твоих каналов под твоим аккаунтом (Telethon), переводит их на английский через бесплатный Gemini API и публикует в «Избранное» или в твой приватный канал.

```
Example News
<перевод с сохранённым форматированием, фото и альбомы тоже переносятся>

📚 Vocabulary
• rate hike — повышение ставки
• to tighten monetary policy — ужесточить ДКП

Original                         ← ссылка на исходный пост
▸ оригинал на русском в свёрнутой цитате
```

## Что видно в публичном репозитории, а что нет

| Публично | Скрыто |
|---|---|
| Код бота, `config.yaml` (уровень английского, число слов и т.п.) | Список каналов (секрет `TG_CHANNELS`) |
| `state.enc`: зашифрованный набор байтов | Куда приходят переводы (`TG_TARGET`) |
| Логи запусков: только «channel #1: 2 new post(s)» | Сессия Telegram, api_id/api_hash, ключ Gemini |
| Время запусков и коммиты «state: update» | Номер телефона, имя, тексты постов |

Секреты GitHub не видны никому, даже в логах (там они заменяются на `***`). Чужие форки и pull request'ы не получают к ним доступа: workflow запускается только по расписанию и вручную.

## Пошаговый план

### Часть 1. Telegram
1. **Включи облачный пароль**, если его ещё нет: Настройки → Конфиденциальность → Облачный пароль. Это защита от входа на новом устройстве по одному SMS-коду.
2. **Получи api_id и api_hash.** Зайди на https://my.telegram.org с номером телефона (код придёт в Telegram) → **API development tools** → заполни форму: App title `translator`, Short name `translator`, Platform `Desktop`, остальное можно не заполнять. Сохрани `api_id` и `api_hash` в менеджер паролей.
3. **Создай канал для переводов** (по желанию, иначе всё будет приходить в «Избранное»): Новый канал → название, например, `News in English` → тип **Частный**.

### Часть 2. Сессия (на своём компьютере)
4. Распакуй архив и в папке `tg-translator` выполни:
   ```bash
   pip install telethon
   python login.py
   ```
   Введи api_id, api_hash, номер телефона, код из Telegram и облачный пароль. Скрипт выведет:
   - список твоих каналов с `@username` (или id для закрытых каналов);
   - строку **TG_SESSION**;
   - строку **STATE_KEY**.

   Сразу скопируй их в менеджер паролей или во временный файл, который удалишь после шага 9. **Никому их не отправляй, мне тоже.** TG_SESSION равна входу в твой аккаунт.

### Часть 3. Gemini
5. Открой https://aistudio.google.com/apikey → **Create API key**. Карта не нужна. Сохрани ключ.

### Часть 4. GitHub
6. **Включи двухфакторную аутентификацию на GitHub**: Settings → Password and authentication. Кто владеет твоим GitHub, тот может добраться до секретов.
7. **Создай публичный репозиторий**, например `tg-translator`, пустой: без README и без .gitignore.
8. **Залей код** из папки `tg-translator`:
   ```bash
   git init -b main
   git add .
   git commit -m "Translator bot"
   git remote add origin https://github.com/<твой-логин>/tg-translator.git
   git push -u origin main
   ```
   Можно пропустить этот шаг: скажи мне название репозитория, и я залью код сам.
9. **Добавь 7 секретов**: репозиторий → Settings → Secrets and variables → Actions → **New repository secret**:

   | Name | Значение |
   |---|---|
   | `TG_API_ID` | api_id из шага 2 |
   | `TG_API_HASH` | api_hash из шага 2 |
   | `TG_SESSION` | строка из шага 4 |
   | `STATE_KEY` | строка из шага 4 |
   | `GEMINI_API_KEY` | ключ из шага 5 |
   | `TG_CHANNELS` | каналы через запятую, например `example_news, another_channel, -1001234567890` (username'ы и id из вывода login.py) |
   | `TG_TARGET` | точное название канала из шага 3 (или его id). Если нужно «Избранное», напиши `me` |

   После этого удали временный файл с ключами, если создавал его.
10. **Первый запуск:** вкладка **Actions** → если GitHub спросит, нажми *I understand… enable them* → слева **translate** → **Run workflow**. Через 1–2 минуты в Telegram придут по 3 последних поста из каждого канала. Дальше всё работает само, раз в 30 минут.

### Часть 5. Проверка и контроль
11. Открой Telegram → Настройки → **Устройства**. Там появится сессия `translator`: это бот. Если что-то покажется подозрительным, завершай её прямо там. Бот сразу потеряет доступ, а аккаунт останется в безопасности. Чтобы бот снова заработал, повтори шаг 4 и обнови секрет `TG_SESSION`.

## Повседневное использование
- **Добавить или убрать канал:** Settings → Secrets → `TG_CHANNELS` → Update. В репозитории при этом ничего не меняется.
- **Настройки** (`level`, `vocab_words`, `show_original`, `models`) лежат в `config.yaml`.
- **Тесты:** `pip install -r requirements.txt pytest && python -m pytest tests`.

## Что важно знать
- GitHub иногда запускает cron с опозданием на 5–15 минут.
- Если дневной лимит Gemini закончился, бот продолжит с того же места при следующем запуске. Посты не теряются.
- Если ключ Gemini неверный или Google отказал в доступе, бот останавливается и ничего не отмечает как прочитанное. Ошибку видно в логе шага `python bot.py`.
- **Начать заново** (снова получить 3 последних поста из каждого канала): очисти содержимое `state.enc` и закоммить.
- Если перевод не удался, придёт пост с пометкой ⚠️ и оригиналом.
- Видео и файлы не пересылаются, есть ссылка на оригинал.
- Остаточный риск: сессия хранится в секретах GitHub. Поэтому важны 2FA на GitHub (шаг 6) и Устройства в Telegram (шаг 11). Максимально безопасный вариант: завести второй аккаунт Telegram, подписать его на каналы и запускать бота под ним. Тогда основной аккаунт вообще ни при чём.
